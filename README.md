Librairie installer:

Flask = Il va gérer tout seul les requêtes et response HTTP
Flask-sqlalchemy = Parle en base de données en Python sans écrire de SQL Brut
Flask-login = Gère qui est connecté
Psycopg2-binary = relie Pyhton et PostgreSQL utiliser par SQLAlchemy
Bcrypt = Hasher les mots de passe
pyotp = générer les codes pour la double authentification (comme Google Authenticator).
